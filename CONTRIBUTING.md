# Contributing to Bike Setup Tracker

Thank you for your interest in contributing to **Bike Setup Tracker**! I welcome bug reports, feature requests, and pull requests from the community.

Please note that while this project accepts contributions, it is an **All Rights Reserved** project (see the [LICENSE](LICENSE) file). By contributing to this project, you agree that your contributions will be licensed under the same terms.

## How to Contribute

### 1. File an Issue
If you've found a bug or have a suggestion for a new feature, please open an issue in the issue tracker.
- Provide a clear and descriptive title.
- Describe the steps to reproduce bugs.
- Explain why a feature would be useful.

### 2. Fork & Branch
- Fork the repository to your own GitHub account.
- Clone the project to your local machine.
- Create a new branch for your feature or bug fix:
  ```bash
  git checkout -b feature/my-new-feature
  # or
  git checkout -b fix/my-bug-fix
  ```

### 3. Make Changes
- Follow standard Flutter and Dart coding conventions.
- Make sure your code is properly formatted (`dart format .`).
- Make sure there are no analyzer errors (`flutter analyze`).
- Run existing and new tests to ensure nothing is broken (`flutter test`).

### 4. Commit & Push
- Write clear, concise commit messages.
- Push your changes to your fork on GitHub.

### 5. Submit a Pull Request
- Open a Pull Request from your branch to the `main` branch of this repository.
- Provide a clear description of the problem you've solved or the feature you've added.
- Reference any related issues (e.g., "Fixes #123").

## Development Setup

1. Make sure you have the [Flutter SDK](https://flutter.dev/docs/get-started/install) installed.
2. Clone your forked repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run the app using `flutter run` or via your IDE.

If you have any questions, feel free to reach out via GitHub issues! I am grateful for your help in improving the project.
