# Release notes v1.6.3+44

```
• Hints are now a swipeable card deck, and you decide when to dismiss them
• Your filters are remembered, so the app opens just as you left it

• Add Setup is easier to spot, and helpful tips show up right when you need them
• Import, export and sharing show clear progress
• Swapping a part no longer needs the Installation Timeline
```
