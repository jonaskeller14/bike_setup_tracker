# 06_v1.7.0 kit posts

Drafts for `build_kit.py 06_v1.7.0`, rendered into `build/marketing/06_v1.7.0/posts/`. Format and
placeholders: [`tool/marketing/posts.py`](../../../tool/marketing/posts.py). Posting rules:
[`../channels.md`](../channels.md). Hooks R19 (image posts) and R20 (the Short) come from
[`../messaging.md`](../messaging.md).

Release posts go out only once 1.7.0 is live in **both** stores. Their base is the "What's New" text
`docs/store/play-store/metadata/en-US/changelogs/46.txt`.

Facts every post may state (checked against release build 46): six languages, no feature flag; the app
follows the device language and falls back to English; Settings → Preferences → Language; catalog text
is written in the language active when an entry is picked, so parts already added keep their names;
Excel, CSV and text exports come in the app language; decimals with a comma or a dot; installing the app
for the first time takes units and time format from the device region. Never imply native-quality
translation (#18), never say bare "installation" or "new installs" when you mean installing the app, and
never mention test sessions, feedback, setup guides, pressure check, bookmarks or the iOS map heading
cone. The screens show manufacturers' names, so every post ends with the disclaimer (`channels.md`).
