# 07_v1.8.0 kit posts

Drafts for `build_kit.py 07_v1.8.0`, rendered into `build/marketing/07_v1.8.0/posts/`. Format and
placeholders: [`tool/marketing/posts.py`](../../../tool/marketing/posts.py). Posting rules:
[`../channels.md`](../channels.md). Hooks R23–R28, C11–C13 and S10 come from [`../messaging.md`](../messaging.md);
the formats from [`../brand.md`](../brand.md), Formats.

The Setup Guides and Pressure Check Shorts (`howto-guide`, `howto-pressure`, `ba-pressure`, `ba-guide`) go out
only once 1.8.0 is live in **both** stores. The other six show released features and can go out any time.

Facts every post may state (checked against the recordings, `07_v1.8.0.vo.md`): Setup Guides and Pressure Check are
opt-in under Settings → Features from 1.8.0; Setup Guides give the manual's starting values for the riding weight,
never the app's own suggestion; Pressure Check shows what the pump reads today for the pressure last set, and the
target stays that value. Tasks are opt-in; km and hour intervals need Strava Sync, the one paid add-on. Never
mention test sessions, feedback, riders or bookmarks. The screens show manufacturers' names, so every post ends with
the disclaimer (`channels.md`).
