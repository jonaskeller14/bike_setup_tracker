# Screenshot-Untertitel — Deutsch

Caption layer of the German store screenshots, shared by App Store and Play Store; `docs/store/screenshots.html`
renders it (`python tool/marketing/render_images.py store-screenshots`). Same frames and order as
`en-US.md`; the first three frames show in search results, so they carry the core promise. Written
for German riders (`docs/marketing/messaging.md`), not word for word: the screen name in the label is
the app's German title.

| Frame | Screen | Caption |
|---|---|---|
| 01 | Garage | Baue deine digitale Garage |
| 02 | Komponente hinzufügen | Gabel, Dämpfer, Reifen & mehr |
| 03 | Setup hinzufügen | Setup in Sekunden festhalten |
| 04 | Setup-Verlauf | Jede Änderung auf einen Blick |
| 05 | Diagramme | Sieh, was wirklich funktioniert |
| 06 | Aufgaben | Nie wieder einen Service verpassen |
| 07 | Karte mit einer Strava-Fahrt | Setups zu deinen Fahrten |
| 08 | Kalender | Fahrt, Setup, Service: ein Blick |
