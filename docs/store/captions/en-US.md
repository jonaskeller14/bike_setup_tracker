# Screenshot captions — English

Caption layer of the store screenshots, shared by App Store and Play Store; `docs/store/screenshots.html`
renders it (`python tool/marketing/render_images.py store-screenshots`). The first three
frames show in search results, so they carry the core promise.

| 05 | Charts | See What Actually Works |

| 07 | Map with a Strava ride | Match Setups to Your Rides |
