# Screenshot captions — Español

Caption layer of the Spanish store screenshots, shared by App Store and Play Store; `docs/store/screenshots.html`
renders it (`python tool/marketing/render_images.py store-screenshots`). Same frames and order as
`en-US.md`; the first three frames show in search results, so they carry the core promise. Written
for Spanish riders (`docs/marketing/messaging.md`), not word for word: the screen name in the label is
the app's Spanish title. Address: "tú"; terms follow the glossary in `CONTEXT.md`. LLM draft, no native review (#18).
