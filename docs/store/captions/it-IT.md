# Screenshot captions — Italiano

Caption layer of the Italian store screenshots, shared by App Store and Play Store; `docs/store/screenshots.html`
renders it (`python tool/marketing/render_images.py store-screenshots`). Same frames and order as
`en-US.md`; the first three frames show in search results, so they carry the core promise. Written
for Italian riders (`docs/marketing/messaging.md`), not word for word: the screen name in the label is
the app's Italian title. Address: "tu"; terms follow the glossary in `CONTEXT.md`. LLM draft, no native review (#18).
