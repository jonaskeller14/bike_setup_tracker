# Sound effects

Subtle clicks, swooshes and pops under the Shorts' voice and music. The packs are gitignored, like
`../music/`; only this README is tracked. Re-download them from
[kenney.nl/assets/category:Audio](https://kenney.nl/assets/category:Audio) into this folder and unpack each
next to its zip (`unzip kenney_ui-audio.zip -d kenney_ui-audio`); a kit's `sounds` name files like
`kenney_ui-audio/Audio/click3.ogg`.
